# Changelog

## [1.2.0] - Renamed to AEGIS
- Repo renamed to **AEGIS** (Agentic Engineering: Governance, Implementation & Scaling)
- Positioned relative to [OASIS](https://github.com/knowledgetrailsai/OASIS) as the reference implementation of its "Intelligence and Agent Engineering" discipline, while remaining fully standalone — see `docs/09-related-frameworks.md`
- Added comparison and adopted-ideas tracking against BMAD-METHOD, AWS AI-DLC, and specs.md
- Added `docs/practices/process-scaling.md` (right-sizing process to task complexity), brownfield-first context detection, and clarifying-questions-in-plans guidance

## [1.1.0] - Start-here overview and worked examples
- Added `docs/00-overview.md` as the single detailed walkthrough and primary entry point
- Added `docs/00-git-workflow-and-automation.md` (branching/PR/merge flow, diagram, automation guidance)
- Expanded `docs/06-metrics.md` with standard SDLC/Agile/PM metrics mapped to agentic adoption
- Expanded worked examples across all seven SDLC phases with prompts and outcomes (`examples/`)
- Renamed generic "agent"/"agents" references to "agentic coding tool(s)" throughout
- Added deployment-model taxonomy (standalone IDE / IDE plugin / CLI / cloud) to tools comparison and agile workflow docs

## [1.0.0] - Initial release
- Core principles, patch-vs-regenerate decision framework, all seven SDLC phase guides
- Risk-tier governance model with escalation triggers
- Evidence-based effort-savings section (flags vendor-claim vs. RCT-measured gap)
- Adoption metrics guide
- Spec, ADR, and risk-tier-checklist templates
- Domain/tooling reference covering 40 domains (dev, data/AI, API, integration, ERP, QA, security, OT, and more)
- PR template with mandatory risk-tier field, CI eval-gate workflow skeleton
